# Guess The Pokemon

React 19 + Vite 7 app using pnpm, Tailwind CSS 4, Biome, and `vite-plugin-pwa`.

## Requirements

- Node `>=20.19.0 || >=22.12.0`
- pnpm `10.15.1`

## Commands

```bash
pnpm install
pnpm dev
pnpm build
pnpm lint
pnpm format
pnpm check
pnpm check:write
```

## PWA

- Installs as a standalone app
- Caches the app shell for offline play
- Supports downloading generation packs so sprite assets stay available offline
